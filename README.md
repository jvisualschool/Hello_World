# Hello World | Particle Experience

인터랙티브 파티클 시스템, 글래스모피즘(Glassmorphism) 디자인, 그리고 부드러운 애니메이션이 적용된 시각적으로 아름다운 "Hello World" 페이지입니다.

## ✨ 주요 기능

- **인터랙티브 파티클 텍스트**: "HELLO WORLD" 텍스트가 수천 개의 파티클로 렌더링되며, 마우스 움직임과 클릭에 반응합니다.
- **글래스모피즘 UI**: 배경 흐림 효과와 섬세한 테두리가 적용된 현대적인 반투명 카드 디자인입니다.
- **앰비언트 애니메이션**: 부드럽게 떠다니는 배경 오브젝트와 자연스러운 등장 애니메이션을 제공합니다.
- **물리 기반 상호작용**: 
    - 마우스를 가져다 대면 파티클이 부드럽게 흩어집니다.
    - **클릭하고 있으면** 강력한 폭발 효과가 발생합니다.
- **3D 틸트 효과**: 화면에서 마우스를 움직이면 메인 카드가 반응하여 입체적으로 기울어집니다.
- **커스텀 커서**: 데스크톱 환경을 위한 세련된 팔로워 커서가 적용되어 있습니다.

## 🚀 기술 스택

- **HTML5 Canvas**: 고성능 파티클 렌더링을 위해 사용되었습니다.
- **Vanilla CSS**: 커스텀 애니메이션, 변수(Variables), 반응형 레이아웃을 구현했습니다.
- **Vanilla JavaScript**: 외부 라이브러리 없이 순수 물리 엔진과 인터랙션 로직을 직접 구현했습니다.

## 📦 사용 방법

모든 최신 웹 브라우저에서 `index.html` 파일을 열기만 하면 됩니다.

1. 리포지토리 클론:
   ```bash
   git clone https://github.com/jvisualschool/Hello_World.git
   ```
2. `index.html` 파일을 브라우저에서 실행하세요.
